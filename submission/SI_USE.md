# Use of Super Intelligence (SI)

Each person logs their own SI use in `submission/si_use/<github-login>.md`, one line per use, same columns. One file each, so nobody's rows conflict.

## Statement for the project page (proposed; Tommy to confirm)

We used Super Intelligence (SI) coding assistants throughout the weekend, each under the direction of one team member. They wrote and tested the pipeline and app code, ran the analysis, drafted the documentation, this page and the slides, and passed work between team members on a shared message board. An SI reviewer was asked to audit the work adversarially part way through; what it found and what we changed are published in `docs/AUDIT.md`. Team members decided the approach, checked the results and chose what to claim.

Three things on the site were made with SI: the illustrative control room on the entry view and the animated schematic of the radar echoes, which are both labelled where they appear, and the narration of the opening story, which is synthetic speech in a copy of a team member's own voice. Every code file written with SI assistance says so in its first comment line, and `submission/si_use/` lists each use, one file per team member. No SI-made picture is presented as data: every map layer, figure and number is computed by the code in this repository from NASA, ISRO and other open data.
