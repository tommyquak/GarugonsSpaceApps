# App

The web map. Track 4, owners Kalent and Jan Hoe.

- A static site with no server, deployed on GitHub Pages.
- Reads `public/layers/layers.json` and the images next to it. The format is in `docs/DATA_CONTRACT.md` section 5.
- Must have: season slider, the one-look layer, layer switches, legend, limits panel. Then the click-a-place chart, then story mode.
- Start with placeholder layers in the contract format. Do not wait for real data.
