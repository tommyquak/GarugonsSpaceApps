Proposed field handoff · review before use03 / next steps and limits

Verify the signal before acting.

Use the ranked blocks to choose a small, reachable set of sites and nearby comparisons for field verification.

Decision boundary. This screening map identifies places to investigate. It does not measure water-table depth, identify a cause, predict fire, or recommend canal work or another intervention.
Suggested field checks
  1. Confirm the locationUse the selected block ID and coordinates; check access and whether the location is actually on mapped peat.
  2. Measure what radar cannotRecord water-table depth if a dipwell is available, canal condition, visible fire evidence and vegetation condition.
  3. Capture a comparisonVisit a nearby block with a different screening class under similar field conditions; record date, GPS and photographs.
  4. Review with local teamsCompare field observations with the radar dates, rainfall timing and fire detections before prioritising any response.
What this report cannot establish
One season, no ground truth. HH fall is not a measured water-table drop. Fire detections can miss small or obscured fires. Changes after rain are based on limited passes; differences in processing between releases add uncertainty. PEATMAP has its own boundary errors. A block label is a screening class produced by explicit thresholds, not a diagnosis.
